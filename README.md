# crunl/homebrew-tap

Homebrew tap for apps not available in homebrew-core.

## Usage

```bash
brew tap crunl/tap
```

## Casks

| Name | Description | Install |
| ---- | ----------- | ------- |
| [clash-nyanpasu](Casks/clash-nyanpasu.rb) | Clash GUI based on Tauri (nightly build) | `brew install --cask crunl/tap/clash-nyanpasu` |
